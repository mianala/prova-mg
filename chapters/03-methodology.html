Methodology: the PROVA‑MG framework

PROVA‑MG — Probabilistic Routing Of Variational Alignments for Malagasy — comprises five interlocking components: heterogeneous co‑inference, typological priors, constrained variational EM, latent‑variable decomposition, and confidence calibration. This chapter formalizes each component and describes how the existing license‑first pipeline is absorbed as the data substrate.

Part Three — A

Five interlocking components

Component 3.1

Heterogeneous foundation‑model co‑inference

Whisper‑large‑v3, MMS, and Wav2Vec2‑BERT are treated as three approximate posteriors over the transcript rather than as competing baselines. Each model encodes a different inductive bias (weak supervision, religious‑text alignment, self‑supervision); their disagreement on a given Malagasy segment is therefore informative.

For each unlabeled segment x the approximate posteriors are computed and a learned routing function is defined:

r : ( q_W(y|x), q_M(y|x), q_B(y|x) ) → { train_high_confidence , route_to_human , hold_in_reserve , discard }

The routing function is trained on the supervised set, using the agreement structure between posteriors as features. Routing is preferred to averaging: averaging is Bayes‑optimal only when teachers are mutually calibrated, which is not the case here.

Component 3.2

Typologically informed Bayesian priors

Malagasy belongs to the Malayo‑Polynesian subgroup. Its phonotactics and morphology overlap measurably with Indonesian, Malay, Cebuano, and Tagalog, all of which have substantially larger text corpora. A phonotactic and morphotactic prior is trained on Austronesian text and incorporated into decoding through a calibrated mixture:

P(y|x) ∝ P_acoustic(x|y) · P_LM_MG(y)^α · P_typ(y)^β

The hypothesis underlying this component is that the family‑level prior regularizes regions of the hypothesis space which a Malagasy‑only language model cannot constrain, because of data sparsity, but a family‑level prior can.

Component 3.3

Constrained variational EM for iterative pseudo‑labeling

On the extended dataset D = D_sup ∪ D_unsup, parameters θ and latent transcripts are inferred jointly:

E‑step:  q*(ỹ|x) = argmin_q KL( q || p_θ(ỹ|x) ) subject to constraints C M‑step:  θ ← argmax_θ E_q*[ log p_θ(y_sup, ỹ_unsup | x) ] + λ R(θ)

The constraint set C constitutes the contribution: a confidence floor, a KL divergence bound on drift between successive iterations, an agreement constraint derived from Component 3.1, and a typological consistency constraint derived from Component 3.2. Under these constraints, convergence and non‑collapse conditions can be derived analytically, which the existing empirical literature on pseudo‑labeling does not articulate.

Component 3.4

Latent‑variable decomposition: dialect, register, code‑switching

The generation process is decomposed into a graphical model with explicit latent variables:

x → ( d , r , c , y ) d = dialect   r = register   c = per‑segment code‑switching language identity

The acoustic model factorizes as p(x|y,d,r) and the language model as p(y|d,c,r). Dialect‑specific adapters condition on d, register parameters on r, and code‑switched segments are routed through a French acoustic model. Phenomena usually treated as separate subproblems thus become a single generative model that admits joint approximate inference.

Component 3.5

Linguistically informed confidence calibration

ASR models are typically overconfident, and miscalibrated confidences would compromise both the routing of Component 3.1 and the constraints of Component 3.3. A post‑hoc calibration model (temperature scaling or isotonic regression) is therefore trained on the supervised set, with features that include model entropy, three‑way teacher agreement, typological likelihood, segment duration, voice‑activity confidence, and dialect‑posterior entropy. The calibrated confidence is the quantity consumed by every downstream constraint.

Unifying claim Low‑resource ASR is approached not as a single model trained on a single objective with a single source of supervision, but as a probabilistic system that aggregates heterogeneous evidence under explicit calibration and explicit constraints. Malagasy serves as the empirical instantiation.
Part Three — B

Integration with the existing data and modeling pipeline

The methodology is not introduced ex nihilo: it absorbs the existing license‑first project as its data substrate and repurposes previously planned modeling steps as components of the framework.

  • The license‑first pipeline produces the gold supervised set and the large licensed unlabeled set, together with the dialect, register, and license metadata consumed by Component 3.4.
  • The planned continued pre‑training of Wav2Vec2‑BERT provides one of the three teachers of Component 3.1.
  • The planned architecture comparison is repurposed: instead of selecting a single winner, the three teachers are retained and co‑infer; the comparison serves to calibrate the routing function.
  • The planned pseudo‑labeling loop is reformulated as the constrained variational EM of Component 3.3, with its safeguards made explicit.
  • The planned dialect adaptation becomes Component 3.4, with dialect treated as a latent variable rather than as a fixed class label.
